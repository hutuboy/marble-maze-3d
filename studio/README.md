# 3D 弹珠迷宫 · AI 版

> AI+∞ 开发者创作大赛第三期「AI 造游戏」参赛作品 · 在线试玩即开即玩，无需安装

倾斜整座迷宫，让弹珠靠重力与惯性滚过墙体、绕开陷阱，抵达金色光柱标记的终点。三关递进：校准场 → 裂隙回廊 → 熔核终局，检查点复活、加速带、冰面一应俱全。

## AI 玩法

- **AI 关卡设计师**：一句话生成可玩迷宫（如「难一点，有熔岩和冰面」），生成后自动校验可解性，还能压缩成分享链接发给朋友。
- **AI 教练（带反馈闭环）**：失败瞬间给出点名方位的具体建议；下一局会先验证上次建议是否见效（「右下角碰撞从 5 降到 1」），见效就肯定、未见效就换策略。
- **AI 自动试玩 Agent**：定制关卡点「AI 演示」，AI 沿安全路径自动通关给你看，任意操作立即接管；动作序列可逐帧复现（144 项 Node + 104 项浏览器自动化断言背书）。
- **每日挑战**：日期种子全球同图，每天一座新迷宫，成绩只与今天的自己比，不影响主线解锁。
- **AI 叙事 / 训练报告**：按主题生成关卡名与赞语，汇总生涯数据生成中文训练报告。

离线 / 本地双击 `index.html` 也能完整游玩，AI 自动降级为本地规则引擎；零运行时依赖，全部素材程序化生成。

源码与手记：https://github.com/hutuboy/marble-maze-3d

## 部署说明（创空间后端）

本目录是魔搭创空间的部署源。后端用纯标准库 HTTP Server：

- 托管游戏静态文件（`index.html` / `game.bundle.js` / `styles.css` / `favicon.svg`）
- 在 `index.html` 注入 `window.__MARBLE_AI_ENABLED__=true`，前端才会启用远程 AI
- `/api/ai/{design,coach,narrative,report}` 代理魔搭推理接口，模型链降级 + 配额闸门

安全：`MODELSCOPE_API_KEY` 只作为创空间 **secret** 注入，不写进代码、不进入公开仓库。

本地游戏仍是纯静态、双击即玩的；本目录只服务于线上参赛版本。

## 换行符约定

静态件必须以 **LF** 提交。Windows 上 `core.autocrlf=true` 会把 `game.bundle.js`
连同 CRLF 一起写进 blob，容器检出的文件字节数会比本地多（每行 +1 字节），
线上 `sha256` 就对不上本地构建。同步到创空间仓库前先
`git config core.autocrlf false`，再用 `git ls-files --eol` 确认是 `i/lf`。
