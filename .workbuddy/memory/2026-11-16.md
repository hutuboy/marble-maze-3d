## P3 优化迭代（可读性 + 上手，三项全部落地）
背景：P0/P1/P2 完成后用户再次问「功能/界面还有哪些值得优化」，基于 P2 后的实拍图与代码复盘给出新三档建议，用户选 P3。P3 聚焦「新玩家前 30 秒看不看得懂」与「大关卡还看不看得清」。

- **小地图自适应**：`src/ui.js` 新增 `export function minimapSize(level)`，逻辑分辨率 `220 + (max(cols,rows)-7)*22` 封顶 320（L1/L2/L3 = 220/286/320），canvas backing store 随关卡放大、展示尺寸仍交给 CSS；静态层缓存失效键从「level 引用」扩为「level 引用 + 尺寸」（`mmSize`），`drawMinimap` 改为先 `ensureStaticLayer` 再读尺寸，避免尺寸变化后沿用旧烘焙。墙线/起点/宝石/弹珠标记按 `S/220` 等比加粗。
- **终点金色化 + 光柱**：`src/scene.js` 终点从绿色改金色（goal emissive 0xffb52e、goalRing 0xffe6a3），新增金色圆柱光柱 `goalBeam` + 悬浮八面体信标 `goalBeacon`，`update()` 里脉冲与自转，`clearBoard()` 里一并置空避免切关残留；这些界面型材质都 `toneMapped:false`。小地图终点改金色准心 + 十字，与青色检查点明确区分。同步：图例 `.dot.goal`、L1 关卡提示、菜单 modal-lead、终点粒子色。
- **一次性情境引导**：`src/records.js` 加 `hints` 字段 + 白名单 `['tilt','checkpoint','boost','ice','goal']` + `sanitizeHints()`（脏值清除）；`markHint(key)` 首次返回 true 并 save，`hintSeen(key)` 查询。`src/game.js` 加 `hintOnce(key,text,tone)`；`setAxis()` 在玩家首次给出有效倾斜（state playing 且 |x|+|z|>0.12）时提示松手回正 + Shift 精细；`handleEvents()` 里检查点/加速带/冰面改为各弹一次详细讲解（宝石即时反馈仍每次显示）。引导状态跨局持久化，`file://` 降级内存时本次会话有效。

### 踩坑与修正
- 浏览器断言「引导状态持久化」初版失败：HTTP 与 `file://` 是不同 localStorage 源，tilt/checkpoint 在 HTTP 源写入、boost/ice 在 file 阶段写入，测试读当前源只看到后两个。改为当前源自包含「markHint 新 key → 立即读回」断言，不跨源假设。
- `npm run shots` 偶发 `Uncaught`（固定 sleep 2.6s 后钩子未就绪）：改为轮询 `window.__marbleMaze.quality/game` 就绪（最多 40×250ms）再固定高画质，稳定出图。
