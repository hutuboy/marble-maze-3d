# 2026-11-07

## 新建：3D 弹珠迷宫游戏（完整可运行项目）
- 工作区根目录即项目根，交付 index.html / styles.css / game.bundle.js / favicon.svg / src(7 个模块) / tests / 启动与构建脚本 / README.md。
- 技术方案：Three.js 0.187.0 经 esbuild 打成单个 IIFE `game.bundle.js`，运行时零 CDN、零后端；物理为自研 2.5D 确定性求解（120 Hz 固定步长 + 子步 CCD 圆 vs AABB 墙体），未用第三方物理引擎；地板/弹珠/熔岩纹理、PMREM 环境反射、全部音效由 Canvas 与 WebAudio 程序化生成，无外部素材。
- 运行：`file://` 双击 index.html 即可（已实测）；或 `npm start` → localhost:5173；`npm run build` 可离线重新打包（node_modules 已随项目存在）。
- 玩法：3 关固定种子 DFS 迷宫 + BFS 可解性校验；键盘/WASD 或左键拖拽控制倾斜，右键拖拽转视角、滚轮缩放；惯性/滚动摩擦/撞墙反弹、空洞坠落与熔岩失败、宝石计分、计时/倒计时、碰撞数、生命、暂停/重开/通关/失败提示、小地图与倾角指示器。
- 验证结果：`npm test` 33/33 通过（含自动控制器在 19.0s / 34.7s / 38.3s 实际滚到三关终点、30 秒随机操作最小净空 0.42 = 球半径、不穿墙不出界）；`npm run test:browser` 19/19 通过（无头 Edge + swiftshader，覆盖 WebGL、键盘全流程、通关/失败、HTTP 与 file:// 双模式零控制台错误）。截图在 tests/shot-*.png。
- 关键实现约束：板倾斜用嵌套 Group（外层 `tiltRoot.rotation.z = tiltZ`，内层 `board.rotation.x = tiltX`，合成 R = Rz·Rx），与物理重力投影 `gx = -g·sin(tiltZ)`、`gz = g·cos(tiltZ)·sin(tiltX)` 严格对应；改动倾斜实现时必须同步修改 physics.js，否则输入方向与视觉倾斜会反向。

## P1 优化迭代（同日晚，五项全部落地）
