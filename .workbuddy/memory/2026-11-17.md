### P1 赛中 AI 教练
- 触发点只在 `Game.fail()`，且有 `canLiveCoach()` 闸门：**每关最多 2 次、两次间隔 ≥8s**，时间源是 `this.now()`（可注入，测试才能构造时间序列）。
- 遥测 `buildTelemetry(phase, reason)` 统一赛后/赛中两条路径，新增 `phase / reason / zone / hotZone / hotCount / tiltLevel`：
  - `zoneOf(x,z)` 按 `level.width/depth` 折九宫格（注意顺序是 `${col}${row}角` →「右下角」，写成「下右角」被自己测试抓出来）；
  - `hotZone()` 统计最近 24 次碰撞的方位众数；
  - `tiltLevel` = 每帧 `min(1, hypot(axis.x, axis.z))` 的均值。
- `localCoach()` 加 `phase === 'fail'` 分支：先点名方位，再按「热点同区 ≥3 次」「满倾角 >0.78」给具体动作，无数据时兜底。
- 线上 prompt（`studio/app.py` 的 `SYSTEMS.coach`）补充字段语义，实测输出：`["左上角5次碰撞且倾角0.88，出弯前务必提前减速","过检查点后改用Shift精细档控速…"]`。

### P1 关卡分享码
- 新建 `src/share.js`：自实现 base64url 编解码（不依赖 `btoa/atob`），**不设 Padding**，末组按 `n <<= pad*6` 左移补齐 —— 第一版漏了这一步，导致「自己生成的码自己不认」，被「分享码可复现同一座迷宫」断言当场抓住。
- 编码 17 元组（含 **seed**，这是复现的关键），带 2 字符校验位（滚动哈希 mod 4096），解码后仍走 `sanitizeLevelInput` + `validateLevelInput`，坏码只返回 reason。
- `#l=` 启动时载入；`hashchange` 只在 `state === 'menu'` 时响应，游玩中不劫持当前局。
- 结算页提供「复制分享链接」（clipboard 失败给明确文案），分享码折叠在按钮下方 `<details>` 里兜底手动复制。

### 顺带修掉的隐性问题
- **自定义关卡污染成绩**：`clearLevel()` 原先无条件 `records.submit(cfg.id)` + `unlock()`，而 AI/分享关卡的 id 是随机 9000+，会导致成绩表持续堆垃圾记录、还白送关卡解锁。现在 `custom` 分支只 `addClear()`（生涯次数），不写成绩、不解锁。

### 排版返工（v1.3.1）
自定义关卡结算页第一版把 210 字符分享码铺成三行等宽大字，弹窗顶到 max-height 且分享码被按钮压住。三次迭代：① 改成 `<details>` 折叠；② 「不计入主线成绩」并入副标题行；③ 分享码挪到按钮下方、`margin: 10px 0 0`、左对齐。最终 `scroll == client == 621px`，按钮完整可见。教训：**这个弹窗的高度预算已经用满，任何新增内容都必须先腾空间**。
